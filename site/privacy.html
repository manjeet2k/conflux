Conflux Browser Extension Privacy Policy

Last updated: {{BUILD_DATE}}

Overview

The Conflux browser extension is a companion utility designed for the free and open-source Conflux Download Accelerator desktop application. Its sole purpose is to send download requests from your web browser to your local Conflux desktop client.

Information We Access

When you explicitly initiate a download with Conflux (via the right-click "Download with Conflux" context menu or automatic download interception), the extension reads the following metadata strictly to fulfill your request:

  • Target URL: The address of the file being downloaded.
  • HTTP Cookies: Session cookies for the specific domain hosting the download. These are included solely so authenticated downloads (such as cloud storage or member portals) do not fail with HTTP 401 Unauthorized or 403 Forbidden errors.
  • Referrer URL: The HTTP Referer header of the originating webpage, required by some download servers to validate the request.
  • User-Agent: The browser's User-Agent string to match request signatures expected by the host server.
  • File Name and Size: The suggested filename and total byte length provided by the browser download event.

Where Your Data Goes

Your data never leaves your computer. All captured information is transmitted locally to the Conflux desktop application using the operating system's standard input and output pipes (WebExtensions Native Messaging API).

  • We operate no remote servers, cloud backends, or third-party proxies.
  • No browsing activity, cookies, URLs, or download logs are ever collected, transmitted, sold, or shared with anyone.

Data Storage

The extension stores your personal extension configuration (such as whether auto-interception is enabled, file extension filters, and excluded domain lists) in your browser's local or synced extension storage (chrome.storage.sync). No download URLs or session cookies are ever written to persistent storage by the extension.

Analytics and Third-Party Code

The Conflux browser extension contains zero tracking scripts, zero advertising networks, and zero telemetry or analytics services. It does not communicate with any external domains except the local native messaging host registered on your device.

Open Source

Conflux is fully open source under the MIT and Apache-2.0 licenses. The complete source code for both the desktop application and this browser extension is publicly verifiable on GitHub at {{REPO_URL}}.
