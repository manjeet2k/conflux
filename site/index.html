Built for the downloads that take forever

Channel bonding

Each connection fetches its own byte ranges at the same time. Faster links take more of the file automatically.

Survives drops

Unplug the phone or lose Wi-Fi mid-download: its chunks move to the links that are still up, and the file stays intact.

Pause, quit, resume

Progress is saved as you go. Resume later, or after a crash, without starting over.

Checks every byte

Strict range validation and change detection; a file that changed on the server is caught, not silently stitched together.

Private by design

No telemetry, no accounts. It only talks to the servers you download from and GitHub for updates.

Updates itself

Signed in-app updates. Running downloads pause before installing and resume after the restart.

How it works

  1. Finds your connections. Conflux lists every network adapter that can carry traffic: Ethernet, Wi-Fi, USB or phone tethering.
  2. Splits the file. The download is cut into byte ranges, and each connection opens its own requests bound to its own address.
  3. Writes in place. Ranges land straight at their position in a pre-allocated file, so there is no merging step at the end.

Bonding helps when the connections are independent (for example home broadband plus a phone's 5G). Two adapters on the same router share that router's speed.

FAQ

Why does Windows say "unknown publisher"?

Code-signing certificates cost money and need identity checks, so the beta isn't signed yet. SmartScreen warns about every unsigned installer. Download only from this page or GitHub Releases, and compare the file's SHA-256 with SHA256SUMS.txt from the same release: Get-FileHash .\Conflux_*_x64-setup.exe.

Is it really free? What data does it collect?

Yes, it's free and open source (MIT or Apache-2.0). It collects nothing. See the privacy statement.

Which systems does it run on?

Windows 10 and 11, 64-bit. It needs the Microsoft WebView2 runtime, which current Windows already has; the standard installer fetches it if missing, or use the offline installer.

How much faster will my downloads be?

Up to the sum of your connections, minus some overhead, when the server allows ranged downloads and your links are independent. A single fast link gains little.

I found a bug or a security issue.

Bugs: open an issue and paste Settings → Copy diagnostics. Security problems: please follow the security policy instead of a public issue.
