What's inside

Small app. Serious engine.

Channel bonding

Every adapter fetches its own byte ranges. Faster links automatically take more of the file.

Hot-swap connections

Plug in a phone mid-download and it joins. Unplug it and its work moves elsewhere.

Pause, quit, resume

Progress is saved as you go, so a crash or reboot doesn't mean starting over.

Checks every byte

Strict range validation and change detection. A file that changed on the server is caught.

Private by design

No telemetry, no accounts. It talks only to the servers you download from and GitHub for updates.

Signed updates

Updates are signature-checked. Running downloads pause before installing and resume after.

Under the hood

Three steps, zero merging.

  1. FindLists every adapter that can carry traffic: Ethernet, Wi-Fi, USB or phone tethering.
  2. SplitCuts the file into byte ranges. Each connection requests its own, bound to its own address.
  3. PlaceRanges land at their exact position in a pre-allocated file. No stitching at the end.

Good questions

FAQ

Why does Windows say "unknown publisher"?

Code-signing certificates cost money and need identity checks, so the beta isn't signed yet, and SmartScreen warns about every unsigned installer. Click More info → Run anyway. Download only from this page or GitHub Releases, and compare Get-FileHash .\Conflux_*_x64-setup.exe with the SHA256SUMS.txt from the same release.

Is it really free? What data does it collect?

Free and open source (MIT or Apache-2.0). It collects nothing. Read the privacy statement.

Which systems does it run on?

Windows 10 and 11, 64-bit. It needs Microsoft WebView2, which current Windows already has. The standard installer fetches it if it's missing, or use the offline installer.

How much faster will my downloads be?

Up to the sum of your connections minus some overhead, when the server allows ranged downloads and your links are independent. Two adapters on the same router share that router's speed. Try the calculator.

I found a bug or a security issue.

Bugs: open an issue and paste Settings → Copy diagnostics. Security problems: please follow the security policy instead.
